隐私政策

DraftCode 在本机编辑代码、文本和 Markdown。

1. 文件

你通过系统文件面板、文件选择器或安全范围书签打开的文件，只在本机用于编辑、查找、预览和导出。应用不会把这些文件自动上传到开发者服务器。

2. iCloud

应用的 iCloud 容器只保存你放进去的文档，数据属于你的 Apple 账户。开发者不运营服务器，也不能读取这些文件。

3. 其他处理

格式化、主题和 Git 信息在本机计算。没有账号、广告或追踪 SDK。这是付费下载的应用，没有 App 内购买。

4. 删除

未保存到 iCloud 的本地文件随你在系统文件里的操作保留或删除。卸载应用会移除应用沙盒里的偏好。

Privacy policy

DraftCode edits code, text, and Markdown on your device.

1. Files

Files you open through the system file panel, the file picker, or a security-scoped bookmark are used on the device for editing, search, preview, and export. The app does not automatically upload them to a developer server.

2. iCloud

The app's iCloud container stores only documents you put there. They belong to your Apple Account. The developer runs no server and cannot read those files.

3. Other processing

Formatting, themes, and Git information are computed on the device. There is no account, advertising, or tracking SDK. The app is a paid download and has no in-app purchase.

4. Deletion

Local files you did not put in iCloud follow the system Files app. Removing the app removes preferences stored in its sandbox.
