隐私政策

1. 无服务器、不跟踪。 智能体技能库 不运行任何自有后端，也不会跟踪你。 2. 数据存放位置。 收藏、保存的搜索、自定义来源、额度快照与令牌仅保存在你的设备上——在启用相应 Apple 服务时保存在你私有的 iCloud / 钥匙串中。 3. 公开技能数据。 技能列表与内容来自公开的 GitHub 仓库。 4. GitHub 与 API 令牌。 连接的 GitHub 账号或粘贴的令牌仅用于以更高额度读取公开技能；Claude/OpenAI 密钥仅用于读取你的官方用量数据。令牌不会发送到其他任何地方。 5. 由你掌控。 你可随时在设置中删除本机保存的全部数据。

用户协议

1. 功能。 智能体技能库 用于浏览、搜索、保存和下载公开的 Agent Skills。 2. 归属。 技能与 README 内容归各自的 GitHub 仓库及许可证所有。 3. 你的责任。 在自己的工具中使用任何技能前，请先自行检查其内容。 4. 额度数据。 用量数字为尽力展示，依赖本机 Claude/Codex 文件、你的令牌以及官方服务商 API，并非权威账单依据。 5. 按现状提供。 本 App 按现状提供，不能替代服务商的账单页面。

Privacy Policy

1. No server, no tracking. SkillForge runs no backend of its own and does not track you. 2. Where your data lives. Favorites, saved searches, custom sources, quota snapshots and tokens stay on your device — or in your private iCloud / Keychain when those Apple services are enabled. 3. Public skill data. Skill listings and content are loaded from public GitHub repositories. 4. GitHub & API tokens. A connected GitHub account or pasted token is used only to read public skills at a higher rate limit. Claude/OpenAI keys are used only to read your official usage data. Tokens are never sent anywhere else. 5. Your control. You can delete everything the app stored on this device at any time in Settings.

Terms of Use

1. What it does. SkillForge lets you browse, search, save and download public Agent Skills. 2. Ownership. Skills and README content belong to their respective GitHub repositories and licenses. 3. Your responsibility. Review a skill before using it in your own tools. 4. Quota figures. Usage numbers are best-effort, based on local Claude/Codex files, your tokens and official provider APIs — not an authoritative billing source. 5. As-is. The app is provided as-is and is not a substitute for the providers' billing pages.
